# Руководство по импорту моделей в Autodesk 3ds Max

## Обзор форматов

### OBJ (Wavefront)
**Рекомендуется для**: 3ds Max 2018 и старше

| Характеристика | Описание |
|----------------|----------|
| Расширение | .obj + .mtl |
| Совместимость | Все версии 3ds Max |
| Геометрия | Полная поддержка |
| Материалы | Базовые (diffuse, specular) |
| PBR | Не поддерживается |
| Текстуры | Через MTL файл |

### GLTF/GLB
**Рекомендуется для**: 3ds Max 2021+

| Характеристика | Описание |
|----------------|----------|
| Расширение | .gltf или .glb |
| Совместимость | 3ds Max 2021+ |
| Геометрия | Полная поддержка |
| Материалы | PBR (metallic-roughness) |
| Текстуры | Встроенные (GLB) |

## Пошаговый импорт OBJ

### Шаг 1: Подготовка

1. Убедитесь, что оба файла (.obj и .mtl) находятся в одной папке
2. Не переименовывайте файлы после экспорта

### Шаг 2: Настройка единиц измерения

```
Customize → Units Setup → System Unit Setup
System Unit Scale: 1 Unit = 1.0 Meters
```

### Шаг 3: Импорт

```
File → Import → Import...
Тип файлов: Wavefront Object (*.OBJ)
Выберите файл .obj
```

### Шаг 4: Настройки импорта OBJ

В диалоговом окне Import OBJ File:

| Опция | Рекомендация |
|-------|--------------|
| Import as single mesh | Отключить (для редактирования частей) |
| Import materials | Включить |
| Flip ZY-axis | Зависит от ориентации |
| Retriangulate | Включить |

### Шаг 5: Проверка

1. Проверьте масштаб модели
2. Убедитесь, что материалы загружены
3. Проверьте нормали (Display → Show Normals)

## Пошаговый импорт GLTF/GLB

### Требования

- 3ds Max 2021 или новее
- Встроенная поддержка GLTF (не требует плагинов)

### Шаг 1: Импорт

```
File → Import → Import...
Тип файлов: GL Transmission Format (*.GLTF, *.GLB)
Выберите файл
```

### Шаг 2: Настройки импорта GLTF

| Опция | Рекомендация |
|-------|--------------|
| Convert Units | Включить (Meters) |
| Import Materials | Включить |
| Import Cameras | Отключить |
| Import Lights | Отключить |

### Шаг 3: Материалы

GLTF материалы автоматически конвертируются в Physical Material 3ds Max.

Проверьте в Material Editor:
- Base Color
- Metalness
- Roughness

## Типичные проблемы и решения

### Проблема: Неправильный масштаб

**Симптом**: Модель слишком большая или маленькая

**Решение**:
```
1. Выберите объект
2. Hierarchy → Affect Pivot Only → Center to Object
3. Введите нужный масштаб или используйте Scale Tool
```

### Проблема: Инвертированные нормали

**Симптом**: Некоторые грани черные или прозрачные

**Решение**:
```
1. Конвертируйте в Editable Poly
2. Выберите проблемные полигоны
3. Flip Normals
```

### Проблема: Отсутствуют материалы

**Симптом**: Модель серая без материалов

**Решение (OBJ)**:
```
1. Проверьте, что .mtl файл в той же папке
2. Переимпортируйте с опцией "Import materials"
```

**Решение (GLTF)**:
```
1. Откройте Material Editor
2. Назначьте материалы вручную
```

### Проблема: Неправильная ориентация

**Симптом**: Модель повернута на 90°

**Решение**:
```
При импорте OBJ включите/отключите "Flip ZY-axis"
```

## Оптимизация модели после импорта

### 1. Объединение объектов

```
Выберите все части → Attach (в Editable Poly)
```

### 2. Оптимизация полигонов

```
Modifiers → Mesh Editing → ProOptimizer
```

### 3. Сглаживание

```
Modifiers → Surface → Smooth
```

## Настройка материалов

### Конвертация в Arnold/V-Ray

#### Для Arnold:
```
1. Откройте Slate Material Editor
2. Создайте ai_standard_surface
3. Подключите Base Color из Physical Material
```

#### Для V-Ray:
```
1. Создайте VRayMtl
2. Перенесите параметры:
   - Diffuse → Base Color
   - Reflection → Metalness (инвертировать Roughness)
```

## Рендеринг

### Настройка освещения

```
1. Create → Lights → Standard → Target Direct
2. Position: (50, 100, 50)
3. Enable Shadows: On
```

### Настройка камеры

```
1. Create → Cameras → Target Camera
2. Position для архитектурной визуализации
3. Lens: 24-35mm для экстерьера
```

## Экспорт из 3ds Max

### В FBX (для Unity/Unreal)

```
File → Export → Export...
Тип: Autodesk FBX
```

### В другие форматы

```
File → Export → Export...
Выберите нужный формат
```

## Рекомендации

1. **Всегда сохраняйте оригинальные файлы** перед редактированием
2. **Используйте систему слоев** для организации
3. **Создавайте резервные копии** проекта
4. **Проверяйте масштаб** сразу после импорта
5. **Тестируйте рендер** на простой сцене
